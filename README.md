# 个人数字档案｜A Living Archive

这是一个纯静态、无需登录即可访问的个人数字档案网页模板。页面使用原创 CSS/SVG 视觉与轻量交互，不包含第三方框架或在线数据收集。

## 当前内容说明

- 所有个人资料、作品、笔记、经历均为待填写占位模板，不代表真实个人信息。
- 网页没有在线编辑/数据库功能；修改内容请编辑 `index.html` 并提交更新。
- 发布前请删除不需要的占位内容，并确认所有公开内容都适合公开访问。

## 启用 GitHub Pages

1. 打开仓库 **Settings**。
2. 在左侧 **Pages** 页面找到 **Build and deployment**。
3. 在 **Source** 中选择 **Deploy from a branch**。
4. Branch 选 `main`，目录选 `/(root)`。
5. 点击 **Save**。
6. 等待 Pages 部署完成后，网站地址应为 `https://758758-758.github.io/`。

若页面未出现 Pages 选项，先确认仓库为 Public，并检查仓库是否已初始化、默认分支是否为 `main`。
